# VERIFIED FACTS

Knowledge entries stored here are verified and supported by evidence. Each entry must include: source, confidence level, verification status, timestamp, and tags for cross-referencing.

## Format

```
### [FACT TITLE]
- **Content:** [Verified statement]
- **Source:** [Where this was verified — include URL, book reference, document name, etc.]
- **Confidence:** HIGH / MODERATE / LOW
- **Verified:** [Date — when the verification was performed]
- **Verified By:** [Who or what performed the verification — optional]
- **Tags:** [topic1, topic2, category] — use lowercase, comma-separated
- **Created:** [Date — auto-generated, YYYY-MM-DD]
- **Last Reviewed:** [Date — when the fact was last reviewed or updated]
```

## Usage Guidelines

- **HIGH confidence**: Directly observed, from official documentation, or peer-reviewed source
- **MODERATE confidence**: From multiple credible sources or reputable reporting
- **LOW confidence**: Single source, anecdotal, or unverifiable claim

## Maintenance

- Review facts periodically and downgrade confidence if contradicted by new evidence
- Remove or mark as deprecated any fact that can no longer be verified
- Cross-reference related facts using consistent tags

## Example

```
### [Python GIL Behavior]
- **Content:** The Global Interpreter Lock allows only one thread to execute Python bytecode at a time
- **Source:** CPython documentation, "Data Structures" chapter
- **Confidence:** HIGH
- **Verified:** 2026-01-15
- **Verified By:** CPython source code review
- **Tags:** programming, python, concurrency, performance
```
